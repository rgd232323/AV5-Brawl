## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Brawlers

Open `/brawlers` to view the public Brawler list. Sign in at `/form_login` to
create entries. The development frontend defaults to the backend at
`http://localhost:5000`; set `NEXT_PUBLIC_API_URL` in `.env.local` when the API
is hosted elsewhere. On a fresh backend database, the administrator is created
once with username `admin` and password `admin123`; the password is stored as a
hash. Use a deployment-specific administrator password before production.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
